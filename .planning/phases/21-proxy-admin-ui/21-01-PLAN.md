<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → backend API | SuperAdmin user agent sends proxy URL + toggle changes over HTTPS; untrusted input crosses here |
| Backend → PostgreSQL | Encrypted credentials persisted; ORM layer prevents injection |
| Backend → public YouTube via residential proxy | Outbound HTTPS test request; proxy URL contains secret credentials |
| Application logs | Any log line is potentially read by ops, GCP log explorers, retention sinks |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01 | Information Disclosure | `get_proxy_config`, `update_proxy_config` response bodies | mitigate | Response model never includes a plaintext `proxy_url` field; only `proxy_url_masked` (bulleted) is exposed. Backend decrypts solely to feed `_mask_proxy_url`; on exception return literal `"[URL configured]"` (no exception detail). |
| T-21-02 | Information Disclosure | Application logger calls in PUT and test endpoints | mitigate | Use `logger.info("SuperAdmin updated proxy URL (credentials not logged)")` and `logger.info(f"SuperAdmin toggled proxy: {payload.proxy_enabled}")` — never f-string the URL. Test endpoint logs no URL on failure. |
| T-21-03 | Elevation of Privilege | All 3 proxy endpoints | mitigate | `Depends(get_current_superadmin)` on every route; `test_proxy_endpoints_reject_non_superadmin` asserts 403 for non-superadmin override. |
| T-21-04 | Tampering | `UpdateProxyConfigRequest.proxy_url` | mitigate | Pydantic shape (`Optional[str]`) plus encrypt-only-on-set semantics: backend never executes the URL, only stores ciphertext and forwards to httpx in test endpoint. SQLAlchemy ORM prevents SQL injection. |
| T-21-05 | Denial of Service | `test_proxy_config` httpx call | mitigate | 5-second hard timeout per D-08 (`timeout=5.0` on `client.get`); errors caught and returned as `{success: false, error}` — no unbounded waits, no crash propagation. |
| T-21-06 | Information Disclosure | Error messages returned to client from test endpoint | mitigate | Catch `httpx.ConnectError` → fixed string `"Connection timed out after 5s"`; broad `except Exception as e` → `str(e)` (httpx exception messages do not contain proxy credentials by inspection, but verify in test). |
| T-21-07 | Repudiation | Audit trail for proxy config changes | accept | `logger.info` line on toggle + URL update provides minimal audit; full audit table out of scope for v1.4. |

**Residual risk:** Low. The only encrypted secret in scope is `proxy_url_encrypted`; it never leaves the backend in plaintext form, never enters logs, and reaches the network only via httpx's proxies parameter inside the test endpoint.

**No package legitimacy gate required:** `httpx` and `cryptography` are already vendored in `backend/requirements.txt` (verified in research §Environment Availability). No new installs.
</threat_model>
