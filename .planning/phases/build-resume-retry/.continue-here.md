## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Creating RUNNING job before worker starts | `initial_status="RUNNING"` + `asyncio.create_task()` creates orphan if dispatch throws | blocking | Use `revive_background_job()` which is atomic — job is RUNNING only after the UPDATE succeeds |
| Marking terminal as FAILED in startup | `startup_scheduler()` marks RUNNING→FAILED (non-retryable) instead of INTERRUPTED | blocking | Task #3 changes this to INTERRUPTED |
| No cleanup on dispatch failure | If `_dispatch_job_retry()` throws after job goes RUNNING, job stays RUNNING forever | blocking | Task #2 adds revert-to-INTERRUPTED in except block |
