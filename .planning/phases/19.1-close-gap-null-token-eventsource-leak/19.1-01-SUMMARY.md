# Plan 19.1-01 Summary: Fix connect() — close-before-open, null guard, counter reset

## What Was Built

Rewrote the `connect()` method in `frontend/src/app/core/services/job-monitor.service.ts` with four surgical changes at the top of the method body:

1. **`this.eventSource?.close()`** — first statement, ensures any live EventSource is closed before a new one opens, even on null-token early return (fixes BLOCKER-03)
2. **`const token = this.authService.getAccessToken()`** — moved to top, reads token once before any URL construction
3. **`if (!token) { this.statusSubject.next('disconnected'); return; }`** — null guard prevents ever constructing a URL with `?token=null` (fixes BLOCKER-02)
4. **`this.reconnectAttempts = 0`** — reset before new EventSource so a fresh `connect()` starts with a full error budget

The event listeners (addEventListener, onopen, onerror) are unchanged.
