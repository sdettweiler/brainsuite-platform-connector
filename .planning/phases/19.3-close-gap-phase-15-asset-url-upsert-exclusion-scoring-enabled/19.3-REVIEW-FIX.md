### CR-01: Dead-code `dv360_asset_queue` assignment in non-DV360 blocks

**Files modified:** `backend/app/services/sync/scheduler.py`
**Commit:** bc0c12e
**Applied fix:** Removed the two dead-code lines inside each `if not is_dv360:` block across all four sync functions (run_daily_sync ~line 263, run_full_resync ~line 1028, run_initial_sync ~line 1379, run_historical_sync ~line 1704). The removed lines were `dv360_asset_queue = result.get("_asset_queue") if platform == "DV360" else None` and `conn_id_for_assets = connection.id if dv360_asset_queue else None` — always evaluating to `None` since `platform == "DV360"` is impossible inside a `not is_dv360` guard. The DV360 second-phase blocks that correctly populate these variables were left untouched.

### CR-02 + WR-01: Fail-safe `scoring_enabled` gate when SystemConfig row is absent

**Files modified:** `backend/app/services/sync/scheduler.py`
**Commit:** 820aff6
**Applied fix:** Changed all four download-function gates from the permissive form `if _system_cfg is not None and not _system_cfg.scoring_enabled` to the fail-safe form `if _system_cfg is None or not _system_cfg.scoring_enabled  # None treated as disabled (fail-safe)`. Applied to `_run_google_ads_asset_downloads` (line 471), `_run_meta_creatives_deferred` (line 607), `_run_tiktok_creatives_deferred` (line 681), and `_run_dv360_asset_downloads` (line 757). Log messages updated to mention the absent-config case. CR-02 and WR-01 were committed together since they modify the same lines.

### WR-02: Separate mock_session from mock_db in `test_downloads_skipped_when_scoring_disabled`

**Files modified:** `backend/tests/services/test_scheduler.py`
**Commit:** 86be15e
**Applied fix:** In `test_downloads_skipped_when_scoring_disabled`, introduced a distinct `mock_session` (AsyncMock with `execute` returning the scalar chain) as the value yielded by the async context manager, while `mock_db` remains the context manager wrapper whose `__aenter__` returns `mock_session`. This eliminates the self-referential pattern where `mock_db` was both the context manager and the session object.

### WR-03: Narrow bare `except Exception` in `test_downloads_proceed_when_scoring_enabled`

**Files modified:** `backend/tests/services/test_scheduler.py`
**Commit:** c90baef
**Applied fix:** Replaced `except Exception: pass` with `except (KeyError, AttributeError, TypeError): pass  # DB/connection attribute failures downstream of the gate are acceptable` and added a comment `# Do not catch Exception — unexpected crashes should surface`. This ensures that unexpected failures (e.g. a broken gate that crashes before `create_background_job`) are not silently swallowed.
