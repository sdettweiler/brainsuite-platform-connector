## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed Wave 1 test mock: scalar_one_or_none declared as AsyncMock instead of MagicMock**
- **Found during:** Task 2 (test execution)
- **Issue:** `mock_scalar.scalar_one_or_none = AsyncMock(return_value=mock_cfg)` — `scalar_one_or_none()` is synchronous in SQLAlchemy; calling it returned a coroutine object instead of `mock_cfg`, causing `AttributeError: 'coroutine' object has no attribute 'scoring_enabled'`
- **Fix:** Changed to `MagicMock(return_value=mock_cfg)` in both test functions
- **Files modified:** `backend/tests/services/test_scheduler.py`
- **Commit:** `97d7671`

**2. [Rule 1 - Bug] Fixed Wave 1 test mock: session factory mock depth too deep for patch(return_value=...) pattern**
- **Found during:** Task 2 (test execution)
- **Issue:** `mock_session_factory = MagicMock(return_value=MagicMock(return_value=mock_db))` — when `patch("...", return_value=mock_session_factory)` is used, the patched `get_session_factory()` call returns `mock_session_factory`; then `mock_session_factory()` returns the inner `MagicMock`, not `mock_db`. `async with inner_MagicMock` does not yield `mock_db`.
- **Fix:** Flattened to `mock_session_factory = MagicMock(return_value=mock_db)` so `get_session_factory()()` → `mock_db` ✓
- **Files modified:** `backend/tests/services/test_scheduler.py`
- **Commit:** `97d7671`

**3. [Rule 3 - Blocking] Wave 1 test files not present in worktree branch (branched before Wave 1 commits)**
- **Found during:** Task 2 (test execution setup)
- **Issue:** Worktree was created from commit `a2fd548`, which predates Wave 1 commits `d060a2d` and `e25577f`. Test files `test_tiktok_sync.py` and `test_scheduler.py` only had pre-Wave-1 content.
