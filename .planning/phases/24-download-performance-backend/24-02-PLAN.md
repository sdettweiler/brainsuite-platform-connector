<objective>
Refactor `backend/app/services/sync/dv360_sync.py` to deliver PERF-01, PERF-03, PERF-04 (caller side), PERF-05, and PERF-06 for the DV360 download path. Splits the current `_do_download_with_cookies` closure into two explicit async functions (`_extract_info`, `_do_download`), reorders retry attempts to put PO-token-first ahead of proxy, replaces inline proxy loading with the cached `get_proxy_config()` from Plan 01, drops the inter-asset sleep when proxy pinning is active, and reduces yt-dlp socket_timeout from 30s to 10s.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cloud Run ↔ YouTube (direct) | Extraction phase fetches metadata directly from YouTube without proxy — datacenter IP could be blocked at network layer |
| Cloud Run ↔ Residential Proxy | Download phase routes stream bytes through residential proxy; sticky session ID in proxy URL |
| Application ↔ Filesystem (temp) | Cookie file written to `/tmp` then deleted in finally; brief on-disk plaintext |
| yt-dlp ↔ stderr/logger | yt-dlp emits proxy URL in error messages by default; `_redact()` strips before logging |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-06 | Information Disclosure | Proxy credentials in yt-dlp log output | mitigate | Preserve existing `_redact()` regex inside `_do_download`; `_YDLLogger.debug/info/warning/error` all wrap `msg` in `_redact()` before forwarding to module logger. Verified by `test_credential_redaction`. |
| T-24-07 | Disclosure | Cookie file plaintext on disk | mitigate | Cookie file written to `tempfile.NamedTemporaryFile(suffix=".txt", delete=False)`; explicit `os.remove(cookie_file.name)` in `finally` block before function exits. Temp directory also removed via `shutil.rmtree(tmpdir, ignore_errors=True)`. |
