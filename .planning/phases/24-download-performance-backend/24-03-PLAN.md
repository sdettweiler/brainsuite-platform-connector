<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cloud Run ↔ YouTube (direct) | Extraction phase fetches metadata directly without proxy — datacenter IP exposed for metadata only |
| Cloud Run ↔ Residential Proxy | Download phase routes stream bytes; sticky session ID in proxy URL |
| Application ↔ Filesystem (temp) | Cookie file written to `/tmp` then deleted in finally |
| yt-dlp ↔ logger | yt-dlp emits proxy URL in error messages; `_redact()` strips before logging |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-13 | Information Disclosure | Proxy credentials in yt-dlp log output (Google Ads path) | mitigate | Preserve existing `_redact()` regex inside `_do_download`; `_YDLLogger` wraps every message through `_redact()` before forwarding to module logger. `test_credential_redaction` covers this. |
| T-24-14 | Disclosure | Cookie file plaintext on disk | mitigate | Cookie file via `tempfile.NamedTemporaryFile(delete=False)`; explicit `os.remove(cookie_file.name)` in `finally`. Temp directory also `shutil.rmtree(tmpdir, ignore_errors=True)`. |
| T-24-15 | Denial of Service | Stuck proxy connection blocks Google Ads download queue | mitigate | `socket_timeout: 10` on both `_extract_info` and `_do_download` ydl_opts (PERF-06). Retry advances; queue continues. |
| T-24-16 | Spoofing | Sticky session ID predictability (Google Ads) | accept | `secrets.token_urlsafe(9)` per-call; 72 bits entropy; not persisted. ASVS V3 compliant. |
| T-24-17 | Tampering | Stale `info_dict` across retries | accept | YouTube format URLs valid ~6 hours; retry runs within seconds. Same trade-off as DV360 (T-24-10). |
| T-24-18 | Information Disclosure | Direct YouTube fetch exposes Cloud Run egress IP for metadata | accept | Metadata-only exposure; payload through proxy. If blocked, fallback path in `_extract_info` retries through proxy. Same disposition as DV360 (T-24-11). |
| T-24-19 | Repudiation | Logs missing job correlation | accept | Existing google_ads_sync.py logging includes `ad_id` and `youtube_video_id`; structure preserved by refactor. |
| T-24-20 | Tampering (parity) | Missing `remote_components` on Google Ads pre-refactor caused PO-first path to silently fall through to proxy+cookies | mitigate | D-05 addresses by adding `"remote_components": "ejs:github"` to both extraction and download ydl_opts. `test_remote_components_present_in_both_phases` enforces. |
</threat_model>
