<objective>
Create the shared proxy config cache module (`backend/app/services/sync/proxy_cache.py`) that exposes `async def get_proxy_config() -> tuple[bool, str | None]` with a 60-second TTL. This is the foundation Plans 02 and 03 depend on — both `dv360_sync.py` and `google_ads_sync.py` will replace their inline proxy-loading blocks with a single call to this cache.

Purpose: Eliminates per-download SystemConfig DB query + Fernet decryption (~5ms each) by reading from memory on cache hits. Required by PERF-04. Also serves the DV360 batch loop's sleep condition (PERF-05, planned in 24-02).

Output:
- `backend/app/services/sync/proxy_cache.py` — module with `_cache` dict, `_cache_lock` asyncio.Lock, `CACHE_TTL_SECONDS = 60`, `async def get_proxy_config()`
- `backend/tests/test_proxy_cache.py` — pytest-asyncio tests covering: cache hit, cache miss/refresh, TTL expiry, concurrent access, DB error fallback
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App memory ↔ Database | Decrypted proxy URL transits from Fernet-protected DB column into application memory (cache) |
| Cache ↔ Concurrent download tasks | Multiple async download coroutines read the same `_cache` dict; without synchronization, dict writes are not atomic in CPython |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Disclosure | Decrypted proxy_url held in module-level _cache for up to 60s | accept | Cache lifetime is short (60s) and limited to a single Cloud Run instance memory; no logs print the cached URL value; existing `_redact()` strips credentials from yt-dlp output downstream. Acceptable per ASVS V6 (cryptography at rest preserved; in-memory plaintext is expected for usage). |
| T-24-02 | Tampering (race) | Concurrent writes to `_cache` dict | mitigate | `_cache_lock = asyncio.Lock()` wraps every read/write in `get_proxy_config()`. Test `test_concurrent_calls_serialize_db_load` enforces serialization. |
| T-24-03 | Denial of Service | DB outage during cache miss | mitigate | `try/except Exception` around `get_session_factory()` call returns `(False, None)` safe defaults; subsequent download attempts continue without proxy rather than blocking; warning logged. |
| T-24-04 | Information Disclosure (logs) | Exception messages from `decrypt_token()` could leak ciphertext fragments | mitigate | Catch `Exception` returns generic warning `"Failed to load proxy config from DB: %s"`; ciphertext is base64 + already public-key-encrypted, low value. ASVS V8 logging compliant. |
| T-24-05 | Spoofing | Module-level `_cache` writable from any importer | accept | Python convention `_` prefix marks private; no public mutation API exposed. Only `reset_cache()` test helper writes from outside `get_proxy_config()`. |
</threat_model>
