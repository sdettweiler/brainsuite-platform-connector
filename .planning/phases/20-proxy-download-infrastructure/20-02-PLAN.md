```python
def _redact(msg: str) -> str:
    """Redact proxy credentials from log/exception message (D-05).
    Pattern: "http://user:pass@geo.iproyal.com:12321" → "http://[PROXY:geo.iproyal.com]:12321"

    if not proxy_url:

```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SystemConfig DB → sync service memory | proxy_url_encrypted decrypted in memory; decrypted value passed only through closure scope; never logged, never written to temp files |
| yt-dlp log output → application logs | _YDLLogger intercepts all yt-dlp messages; _redact() strips credentials before any logger.* call reaches stdout/CloudWatch |
| Proxy provider network → yt-dlp | HTTP proxy (not HTTPS tunnel); traffic between app container and IPRoyal endpoint is plaintext. Mitigated by IPRoyal's provider-side TLS; low-risk for ad creative downloads (public content) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-05 | Disclosure | _YDLLogger.debug/info/warning/error | mitigate | All four methods call `_redact(msg)` before logging; `grep -c "_redact(msg)" dv360_sync.py` must return 4 (enforced by acceptance_criteria) |
| T-20-06 | Disclosure | Exception message in except block | mitigate | `_redact(str(e))` applied before `logger.error()`; yt-dlp may include proxy URL in exception text (confirmed common in yt-dlp issue #10930) |
| T-20-07 | Spoofing | Session ID reused across jobs | mitigate | `secrets.token_urlsafe(9)` called once per `_download_video_asset` invocation, outside retry loop; acceptance_criteria enforces `grep -c "token_urlsafe" == 1` per file |
| T-20-08 | Tampering | Proxy disabled but still applied | mitigate | Both injection gates check `if proxy_enabled and proxy_url` (not just `if proxy_url`); ensures ops disable via Phase 21 UI takes immediate effect |
| T-20-09 | Disclosure | proxy_url in closure scope leaking to outer scope | accept | proxy_url is a local variable in `_download_video_asset`; Python closure scope prevents it from escaping to module level; no risk beyond normal function lifetime |
| T-20-10 | Tampering | Proxy injection order (after vs before YoutubeDL instantiation) | mitigate | ydl_opts["proxy"] set BEFORE `with yt_dlp.YoutubeDL(ydl_opts)` — wrong order would silently bypass proxy for info extraction (confirmed pitfall in RESEARCH.md); acceptance_criteria verifies with grep |
