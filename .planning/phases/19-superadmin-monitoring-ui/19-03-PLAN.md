1. Export the `SseStatus` and `JobSnapshot` types at the top of the file (before the class).

2. Service class fields:
   - `private jobMap = new Map<string, JobSnapshot>()` — in-memory store keyed by job_id
   - `private jobsSubject = new BehaviorSubject<JobSnapshot[]>([])` — emits whenever the map updates
   - `jobs$ = this.jobsSubject.asObservable()` — public readonly observable
   - `private statusSubject = new BehaviorSubject<SseStatus>('reconnecting')` — SSE connection state
   - `connectionStatus$ = this.statusSubject.asObservable()` — public readonly observable
   - `private eventSource: EventSource | null = null`
   - `private reconnectAttempts = 0`

3. Constructor: `constructor(private ngZone: NgZone, private authService: AuthService, private api: ApiService) {}`

4. `connect()` method — builds `const url = `/api/v1/jobs/stream?token=${token}``. Wraps all EventSource callbacks in `this.ngZone.run(() => { ... })`. On `job_update` event: parse JSON, upsert into jobMap, emit `Array.from(this.jobMap.values())`. On `onopen`: reset reconnectAttempts to 0, emit 'live'. On `onerror`: increment reconnectAttempts, emit 'reconnecting' if < 3 attempts, 'disconnected' if >= 3.

5. `disconnect()` method — closes eventSource and sets it to null.

6. `clearJobMap()` method — clears the Map and emits empty array.

7. REST helper methods (use `this.api`):
   ```typescript
   getJobs(jobType?: string, status?: string, limit = 50, offset = 0): Observable<JobSnapshot[]> {
     let path = `/jobs?limit=${limit}&offset=${offset}`;
     if (jobType) path += `&job_type=${jobType}`;
     if (status) path += `&status=${status}`;
     return this.api.get<JobSnapshot[]>(path);
   }

   getJobDetail(jobId: string): Observable<any> {
     return this.api.get<any>(`/jobs/${jobId}`);
   }

   clearJobs(jobType: string, status: string): Observable<void> {
     return this.api.delete<void>(`/jobs?job_type=${encodeURIComponent(jobType)}&status=${encodeURIComponent(status)}`);
   }
   ```

8. `ngOnDestroy()`: call `this.disconnect()`.

Critical implementation notes:
- NgZone.run() is MANDATORY on ALL EventSource callbacks (job_update listener, onopen, onerror). Missing this causes OnPush components to silently miss updates.
- Import `NgZone` from `@angular/core`, `BehaviorSubject, Observable` from `rxjs`, `AuthService` from `./auth.service`, `ApiService` from `./api.service`.
- The service must implement `OnDestroy` from `@angular/core`.
