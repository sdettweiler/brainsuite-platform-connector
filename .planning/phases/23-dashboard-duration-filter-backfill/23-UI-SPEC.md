## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / option text | 13px | 500 (medium) | 1.4 |
| Label / chip text | 13px | 500 (medium) | 1.4 |
| Slider label / slider values | 12px | 700 (bold) | 1.4 |
| Badge / micro label | 9px | 700 (bold) | 1.0 |

Notes:
- 13px is the canonical toolbar/filter text size in this project (confirmed from `.tbd-trigger`, `.tbd-option`, `.tbd-check`).
- 12px at weight 700 is used exclusively for `.slider-label` and `.slider-values`. The existing score slider used 600; Phase 23 consolidates to 700 (the visual difference between 600 and 700 at 12px is imperceptible). Use weight 700 for the duration slider label and value display.
- The NULL duration callout text uses 13px at weight 500 — matches the chip row typography.
- Do NOT introduce any new font size for Phase 23. Use 13px for interactive text, 12px for slider label/values, 9px for badges only.
- Weights are restricted to exactly 2: 500 (interactive elements, callout text) and 700 (slider label/values, badges). No other weights for Phase 23 elements.

Source: `dashboard.component.ts` styles lines 1033–1047 (score slider) + Phase 22 UI-SPEC.

Accent (`#FF7700`) reserved for:
1. `ngx-slider-pointer` border — `border: 2px solid var(--accent)` (handles) — inherited from existing score slider `::ng-deep` rules

## Visual Focal Points

Primary new visual element: the `duration-slider-wrapper` row — the dual-handle ngx-slider placed in the toolbar row to the right of the score slider (or in a new toolbar group if layout width is constrained). It follows the exact visual language of the score slider wrapper already present.

Secondary anchor: the NULL duration callout — rendered below the chip row (per D-08) as a single line of small info text with an accent-colored `bi-info-circle` icon. Appears only when the duration filter is active and `nullDurationCount > 0`.

The slider is completely absent (not disabled, not hidden with opacity) when `hasVideoAssets` is false (D-04). Do not introduce a placeholder or greyed-out slot.

No additional visual anchors. The duration slider should feel like a natural sibling to the score slider.

## Component Inventory

### New: Duration Range Slider (DASH-03)

**Wrapper element:**
- CSS class: `duration-slider-wrapper` — copy the existing `score-slider-wrapper` rules verbatim: `display: flex; align-items: center; gap: 8px; min-width: 280px; max-width: 380px; padding: 0 8px`
- Visibility: `*ngIf="hasVideoAssets"` — completely absent from DOM when false (D-04)
- Placement: in the toolbar group, after the score slider, before the `toolbar-spacer`

**Label:**
- `<span class="slider-label">Duration</span>` — `font-size: 12px; font-weight: 700; color: var(--text-muted); white-space: nowrap`
- Reuses `.slider-label` class already defined; update the existing CSS rule weight from 600 to 700

**ngx-slider:**
```html
<ngx-slider
  [(value)]="durationMin"
  [(highValue)]="durationMax"
  [options]="durationSliderOptions"
  (userChangeEnd)="onDurationChange()"
></ngx-slider>
```
- `flex: 1` — inherits from `ngx-slider { flex: 1 }` rule already in `::ng-deep .score-slider-wrapper ngx-slider`; add equivalent rule for `.duration-slider-wrapper ngx-slider`
- All `::ng-deep .ngx-slider` rules (pointer, selection, bar, bubble, disabled) are shared — no new `::ng-deep` block needed

**Value display:**
- `<span class="slider-values">{{ formatDuration(durationMin) }} – {{ formatDuration(durationMax) }}</span>`
- Reuses `.slider-values` class: `font-size: 12px; font-weight: 700; color: var(--text-secondary); white-space: nowrap; min-width: 50px; text-align: center`
- Update the existing CSS rule weight from 600 to 700 when applying to the duration slider
- Uses em dash (–) as separator — matches existing score slider display convention

**State variables (add to class):**
```typescript
durationMin = 0;
durationMax = 3600;          // fallback; overwritten by loadDurationBounds()
hasVideoAssets = false;
nullDurationCount = 0;
loadingDurationBounds = false;
durationSliderOptions: Options = {
  floor: 0,
  ceil: 3600,
  step: 1,
  noSwitching: true,
  disabled: false,
  translate: (value: number) => this.formatDuration(value),
};
```

**Format helper:**
```typescript
formatDuration(seconds: number): string {
  const m = Math.floor(seconds / 60);
  const s = Math.round(seconds % 60);
  return m > 0 ? `${m}m ${s}s` : `${s}s`;
}
```
- Source: CONTEXT.md §Specifics — locked implementation
- Examples: 15 → `"15s"`, 135 → `"2m 15s"`, 3600 → `"60m 0s"`
- Used in: slider `translate` callback, `.slider-values` display, duration chip label

**Tooltip on slider wrapper:**
- Add `[matTooltip]="loadingDurationBounds ? 'Loading duration data…' : ''"` to the `duration-slider-wrapper` div — provides feedback during bounds fetch. Uses existing `MatTooltipModule` (already imported).

### New: Duration Filter Chip (in existing chip row)

Duration chip appears in the existing `metadata-chip-row` after the metadata chips when a duration filter is active (durationMin > durationSliderOptions.floor OR durationMax < durationSliderOptions.ceil).

- Element: `<div class="metadata-chip">` — reuse the existing chip CSS class verbatim; no new chip variant
- Chip label: `"Duration: {{ formatDuration(durationMin) }} – {{ formatDuration(durationMax) }}"` (e.g. `"Duration: 15s – 2m 15s"`)
- Dismiss button: `<button class="chip-dismiss" (click)="clearDurationFilter()" aria-label="Remove duration filter" title="Remove filter"><i class="bi bi-x"></i></button>`
- `clearDurationFilter()` resets `durationMin` / `durationMax` to `durationSliderOptions.floor` / `durationSliderOptions.ceil` and calls `onFilterChange()`

The `chip-clear-all` button logic (shown at ≥ 2 active chips) already handles the combined chip count — duration chip participates naturally once it uses the same `metadata-chip-row` container.

### New: NULL Duration Callout (DASH-03, D-06–D-08)

Renders **below the chip row** as a sibling `<div>`, only when the duration filter is active AND `nullDurationCount > 0`.

**Template:**
```html
<div class="duration-null-callout"
     *ngIf="isDurationFilterActive && nullDurationCount > 0">
  <i class="bi bi-info-circle"></i>
  <span>{{ nullDurationCount }} video{{ nullDurationCount !== 1 ? 's' : '' }} have no duration data and are excluded from this filter</span>
</div>
```

**CSS:**
```scss
.duration-null-callout {
  display: flex;
  align-items: center;
  gap: 8px;
  margin-top: 4px;
  margin-bottom: 4px;
  font-size: 13px;
  font-weight: 500;
  color: var(--text-secondary);

  .bi-info-circle {
    font-size: 13px;
    color: var(--accent);
    flex-shrink: 0;
  }
}
```

**Computed property:**
```typescript
get isDurationFilterActive(): boolean {
  return this.durationMin > this.durationSliderOptions.floor
      || this.durationMax < this.durationSliderOptions.ceil;
}
```

### Modified: Dashboard Asset Response Handling

`loadData()` response handler additions:
```typescript
this.hasVideoAssets = res.items.some((a: any) => a.asset_type === 'video');
this.nullDurationCount = res.null_duration_count || 0;

if (this.hasVideoAssets) {
  this.loadDurationBounds();  // recompute bounds after other filters change (D-02)
}
```

Duration filter param appended only when active (parallel to score filter pattern, line 1765–1766):

if (this.isDurationFilterActive) {
  params['duration_min'] = this.durationMin;

## Accessibility Contract

- Duration slider wrapper: `aria-label="Duration filter"` on the `<div class="duration-slider-wrapper">` element
- ngx-slider handles: accessibility labels are driven by the `translate` callback in `Options` — `formatDuration(value)` returns human-readable strings (`"15s"`, `"2m 15s"`); ngx-slider renders these as `aria-label` on the pointer elements automatically
- Duration chip: `role="listitem"` (inside `metadata-chip-row` which is already a list context); dismiss button: `aria-label="Remove duration filter"` + `title="Remove filter"`
- NULL duration callout: `role="status"` on the callout div — allows screen readers to announce the count when it changes without moving focus
- NULL callout `bi-info-circle` icon: `aria-hidden="true"` — decorative; the text span carries the message
- Keyboard: Escape closes any open panel and returns focus to trigger button (existing behaviour, no change needed)
- Tab order: duration slider wrapper follows score slider in DOM order; chip follows existing metadata chips in chip row
