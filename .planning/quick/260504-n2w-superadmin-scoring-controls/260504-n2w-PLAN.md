# Quick Task 260504-n2w: Superadmin Scoring Controls

## Goal
Add superadmin API controls for the BrainSuite scoring pipeline:
1. Global toggle to activate/deactivate auto-scoring (affects all orgs)
2. Reset org assets back to UNSCORED (for FAILED/COMPLETE assets)
3. Per-org scoring quota — max assets that can be scored; once reached, new jobs are not triggered

## Architecture Context
- `SystemConfig` singleton table → add `scoring_enabled: bool` (global toggle)
- `OrgBrainsuiteConfig` per-org table → add `scoring_quota: Optional[int]` (nullable = unlimited)
- `run_scoring_batch()` in `scoring_job.py` → check toggle at entry, check quota per-org before batching
- `super_admin.py` → 3 new endpoint groups

## Task 3: Superadmin endpoints

**Files:**
- `backend/app/api/v1/endpoints/super_admin.py`

**Action — add 4 endpoints:**

### GET /super-admin/scoring/config
Returns global scoring toggle + list of all orgs with their quota and current scored asset count.

Response:
```json
{
  "scoring_enabled": true,
  "organizations": [
    {"org_id": "...", "org_name": "...", "quota": null, "scored_count": 12, "pending_count": 0}
  ]
}
```

### PUT /super-admin/scoring/config
Payload: `{"scoring_enabled": bool}`
Updates `SystemConfig.scoring_enabled`.

### PUT /super-admin/scoring/orgs/{org_id}/quota
Payload: `{"quota": int | null}` — null removes the quota (unlimited)
Updates `OrgBrainsuiteConfig.scoring_quota`.
Returns 404 if org has no BrainSuite config row.

### POST /super-admin/scoring/orgs/{org_id}/reset
Payload: `{"statuses": ["FAILED", "COMPLETE"]}` — which statuses to reset (default: FAILED only)
Resets all matching `CreativeScoreResult` rows to UNSCORED, clearing `total_score`, `total_rating`, `score_dimensions`, `scored_at`, `error_reason`.
Returns: `{"reset_count": N}`

**Security:** All 4 require `Depends(get_current_superadmin)`. The reset endpoint explicitly excludes PROCESSING (per project rule: never reset live job IDs).

**Verify:**
- 4 new routes present in super_admin.py
- PROCESSING status never touched in reset endpoint

**Done:** All 4 endpoints implemented and registered
