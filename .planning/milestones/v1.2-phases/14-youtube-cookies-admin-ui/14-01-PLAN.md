## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Tampering | JWT is_superuser claim | mitigate | JWT signed with SECRET_KEY (HS256); claim cannot be forged without key. get_current_superadmin verifies is_superuser from the User model loaded via DB (not from JWT alone) -- the JWT sub is used to load user from DB in get_current_user, then is_superuser is read from the DB model. |
| T-14-02 | Tampering | system_config multiple rows | mitigate | UNIQUE constraint on singleton_guard column prevents INSERT of second row at DB level. |
| T-14-03 | Elevation of Privilege | get_current_superadmin bypass | mitigate | Dependency raises HTTP 403 before any endpoint logic executes. No public endpoint sets is_superuser -- only Alembic migration seeds it. |
| T-14-04 | Information Disclosure | is_superuser in JWT | accept | Boolean flag reveals role but no sensitive data. JWT is transmitted over HTTPS only. |
</threat_model>
