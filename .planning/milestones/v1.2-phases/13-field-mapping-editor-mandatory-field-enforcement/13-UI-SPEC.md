## Spacing Scale

Declared values (all multiples of 4 — mapped to existing usage in `brainsuite-apps.component.ts` and `platforms.component.scss`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, row gap between default-flags |
| sm | 8px | Gap between form action buttons, toggle label gap, panel body field mapping row vertical padding |
| md | 16px | Default element spacing, grid column gap, panel body row padding horizontal complement, sticky banner vertical padding |
| lg | 24px | Section body padding, panel header padding horizontal, panel footer padding, banner horizontal padding |
| xl | 32px | Accordion panel top padding, page-container column gap |
| 2xl | 48px | Empty-state padding (vertical) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Panel body field mapping rows: `8px` vertical padding, `24px` horizontal padding — compact density appropriate for Angular Material 36px-height compact form elements
- Toggle switch touch target minimum: 44px minimum row height — **a11y-touch-target constraint only, not a layout spacing value**; this is a WCAG 2.5.5 minimum tap area requirement, not part of the spacing grid
- Sticky warning banner: `16px` vertical padding, `24px` horizontal padding — uses `md` and `lg` tokens from declared scale

## Typography

All sizes are sourced from `styles.scss` global type scale and confirmed in `brainsuite-apps.component.ts` inline styles.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 13px | 400 (regular) | 1.5 |
| Label / UI text | 13px | 600 (semibold) | 1.4 |
| Section heading | 16px | 600 (semibold) | 1.2 |
| Panel title | 18px | 600 (semibold) | 1.2 |

Notes:
- Body and Label both use 13px — hierarchy is achieved exclusively through weight: body = 400 (regular), label = 600 (semibold). No separate 14px size is introduced for Phase 13.
- Phase 13 declared weight scale: **2 weights only — 400 (regular) and 600 (semibold)**. Weight 500 is not introduced for any new Phase 13 elements (it appears in pre-existing platform list code at `app-name` but is outside this phase's scope).
- 11px used for sticky column headers inside the panel body — pre-existing pattern from `platforms.component.scss` (`connections-table thead th`). Not a new size for Phase 13; acknowledged here for completeness.
- 10px used only for uppercase table column headers (letter-spacing 0.5px, weight 600) — not a new size, already established.
- 12px used only for helper text / muted captions (`accordion-helper`, `app-desc`) — not a named body size.

## Color

All tokens are CSS custom properties declared in `.dark-theme` / `.light-theme` blocks in `styles.scss`. Phase 13 uses no new color values.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg-primary)` — dark `#1B1B1B` / light `#F5F6FA` | Page background |
| Secondary (30%) | `var(--bg-card)` — dark `#2C2C2C` / light `#FFFFFF` | Slide panel background, section cards, accordion panel |
| Accent (10%) | `var(--accent)` — `#FF7700` | Reserved list below |
| Warning semantic | `var(--warning)` — `#F39C12` + `rgba(243,156,18,0.06)` bg | Incomplete-config sticky banner only |
| Destructive | `var(--error)` — `#E74C3C` | Delete custom field confirm, mandatory-row tint alternative (see below) |

**Accent (`#FF7700`) reserved for:**
- "Configure Field Mappings" trigger button label/icon (stroked, accent color text)
- Save button fill (`mat-flat-button` `.save-btn` pattern — white text on accent background)
- Toggle switch thumb when ON (Angular Material checkbox/slide-toggle checked state — `--accent` already wired in `styles.scss`)
- Focused outline on mat-select dropdowns inside the panel (already global)
- Chevron icon when accordion is expanded (existing `.chevron-expanded` class)

**Mandatory row tint when toggle ON:**
- Use `rgba(255, 119, 0, 0.06)` background on the row (accent-light variant, same approach as `accent-light` = `rgba(255,119,0,0.15)` but lighter so text stays readable)
- Do NOT use red/error tint for mandatory rows — reserve `var(--error)` for destructive delete actions only

**Sticky warning banner color:**
- Background: `rgba(243,156,18,0.06)` (matches existing `api-note` pattern)
- Border: `rgba(243,156,18,0.3)`
- Icon color: `#F09300` (same as `api-note i.bi`)
- Text: `var(--text-secondary)`
- This is a warning variant of `api-note` — use CSS class `api-note api-note--warning` (or new `config-warning-banner` that inherits from `api-note` styling)

## Component Inventory

### 1. Sticky Incomplete-Config Warning Banner (PIPE-03)

**Location:** Top of `.page-container`, above all `config-section` cards.

**Visibility:** Shown when any of: missing credentials, any app with null `system_app_name`, or any mandatory field with no metadata mapping. Hidden when all conditions resolved.

**Structure:**
```
[bi-exclamation-triangle icon]  "BrainSuite configuration is incomplete"
                                  [list of specific gaps, e.g. "Missing credentials · Video App has no app name"]
```

**CSS class:** `.config-warning-banner` — extends `api-note` styling pattern:
- `display: flex; gap: 8px; padding: 16px 24px; background: rgba(243,156,18,0.06); border: 1px solid rgba(243,156,18,0.3); border-radius: 8px;`
- `position: sticky; top: 0; z-index: 10;` — sticks at top during scroll
- Icon: `bi-exclamation-triangle`, color `#F09300`, font-size 18px
- Text: 13px / 400 / `var(--text-secondary)`
- Gap items separated by ` · ` (interpunct + spaces)

**Interaction:** No dismiss button. Auto-disappears when all conditions resolved.

### 2. "Configure Field Mappings" Trigger Button (D-01)

**Location:** Inside the expanded `accordion-panel` for each BrainsuiteApp, below the `BrainSuite API App Name` field and its helper text, above the `.form-actions` row.

**Component:** `mat-stroked-button` with icon.

**Copy:** `Configure Field Mappings`

**Icon:** `bi-sliders` (left of label), 16px

**Style:**
- Stroked (outline) button, accent-colored label: `color: var(--accent) !important;`
- Full-width within accordion, or left-aligned — left-aligned preferred (matches "Delete" button alignment)
- Not disabled; always clickable once accordion is open

### 3. Field Mapping Slide Panel (D-02, D-03)

**Reuse:** `slide-panel`, `slide-backdrop`, `panel-header`, `panel-body`, `panel-footer` CSS classes already defined in `platforms.component.scss`. Import or copy into the new `FieldMappingPanelComponent` inline styles.

**Dimensions:** 480px wide, full viewport height (`position: fixed; top: 0; right: 0; bottom: 0;`). `max-width: 90vw` for small screens.

**Animation:** `transform: translateX(100%)` → `translateX(0)` on open, `0.3s cubic-bezier(0.4, 0, 0.2, 1)`. Backdrop opacity `0` → `1` over `0.3s ease`.

**Panel Header (`.panel-header`):**
- Line 1: App name (16px / 600) + app-type badge (`app-type-badge` class from `brainsuite-apps.component.ts`) — e.g. "My Video App" + `VIDEO` badge
- Line 2: `13px / 400 / var(--text-secondary)` — "Map metadata fields to BrainSuite API fields"
- Right: `mat-icon-button` with `bi-x-lg` (close), `aria-label="Close panel"`

**Panel Body (`.panel-body`):**

Split into two sections, each with a `11px / 600 / var(--text-muted) / uppercase / letter-spacing: 0.5px` label:

**Section A — "Standard Fields"**
- Section label: `STANDARD FIELDS` — 11px, 600, uppercase, `var(--text-muted)`, padding `8px 24px`
- One row per standard field (12 for VIDEO, 8 for STATIC)
- Row layout: 3 columns in a grid `grid-template-columns: 1fr 1.5fr auto`
  - Col 1: API field name — 13px / 400 / `var(--text-primary)`, not editable, truncated with ellipsis
  - Col 2: `mat-select` (outline appearance, compact — 36px height using `.compact-select` pattern from `platforms.component.scss`) showing all org metadata fields + "— Unmapped —" as first option
  - Col 3: Angular Material `mat-slide-toggle` sized small; label: none (column header provides context)
- Row padding: `8px 24px`
- Row with mandatory toggle ON: background `rgba(255, 119, 0, 0.06)`; API field name gains `bi-asterisk` icon (12px, `var(--accent)`) prepended inline

**Section B — "Custom Fields"**
- Section label: `CUSTOM FIELDS` — same style as above, padding `16px 24px 8px`
- One row per existing custom field — same 3-column grid PLUS a 4th column for `bi-trash` delete icon button
  - Col 1: editable text input (API field name), 13px outline mat-input, compact height 36px
  - Col 2: same `mat-select` as standard fields
  - Col 3: `mat-slide-toggle`
  - Col 4: `mat-icon-button` with `bi-trash`, `color: var(--error)`, `aria-label="Delete field"`
- Below custom field rows: `+ Add custom field` row
  - Display: flex, gap 8px, padding `8px 24px`
  - Left element: plain `mat-stroked-button` — `bi-plus-lg` icon + label `Add custom field`, 13px, `color: var(--accent)`
  - Clicking reveals a new inline empty row (same 4-column grid) with blank inputs focused

**Column header row** (sticky within `.panel-body`):
- `position: sticky; top: 0; background: var(--bg-secondary); z-index: 1; border-bottom: 1px solid var(--border);`
- 3 columns: `API Field` | `Metadata Field` | `Mandatory`
- 11px / 600 / uppercase / letter-spacing 0.5px / `var(--text-muted)` — matches `connections-table thead th`
- Padding: `8px 24px`

**Panel Footer (`.panel-footer`):**
- Right-aligned, gap 8px
- Discard Changes: `mat-stroked-button` — "Discard Changes"
- Save: `mat-flat-button` `.save-btn` — "Save Mappings" (accent fill, white text)
- Saving state: spinner 16px inside Save button, label "Saving..."
- "Discard Changes" closes panel without saving, discards all unsaved changes (D-10)

## Interaction States

### Slide Panel
| State | Visual |
|-------|--------|
| Closed | `transform: translateX(100%)` — off-screen. Backdrop invisible. |
| Opening | Both animate simultaneously over 300ms. |
| Open | `transform: translateX(0)`. Backdrop `rgba(0,0,0,0.5)` opacity 1. |
| Closing | Reverse animation. Triggered by: "Discard Changes" button, close `bi-x-lg` (`aria-label="Close panel"`), backdrop click. |
| Saving | Save button shows spinner, is disabled. "Discard Changes" stays enabled. |
| Saved | Panel closes, `MatSnackBar` shows "Field mappings saved" for 3000ms. |
| Save failed | Panel stays open. Save button re-enables. `MatSnackBar` shows "Failed to save mappings — please try again." for 4000ms (panelClass: `snack-error`). |

### Mandatory Toggle Row
| State | Visual |
|-------|--------|
| OFF (default) | Row background transparent. No icon on field name. |
| ON | Row background `rgba(255,119,0,0.06)`. `bi-asterisk` (12px, `var(--accent)`) prepends field name. Slide-toggle thumb orange. |

### Metadata Field Dropdown
| State | Visual |
|-------|--------|
| Unmapped | Shows "— Unmapped —" as selected option, `var(--text-muted)` color |
| Auto-matched (unsaved) | Shows matched field name, no special treatment — same as user-selected |
| Mapped | Shows metadata field label, `var(--text-primary)` |

### Custom Field Row
| State | Visual |
|-------|--------|
| Adding | New row with empty inputs appears, API field name input is auto-focused |
| API name empty on Save | Inline validation: input border turns `var(--error)` color; error message "API field name is required" appears below the input at 12px / 400 / `var(--error)`; row does not save |
| Deleting | Immediate optimistic removal from DOM; deletion included in next Save payload (not API-called independently) |

### Sticky Warning Banner
| State | Visual |
|-------|--------|
| Incomplete config | Banner visible with amber styling and `bi-exclamation-triangle` |
| Config resolved | `*ngIf` removes banner from DOM with no animation needed |

## Auto-Match Behavior (D-06)

When the panel opens for an app with zero saved mappings, the frontend pre-fills dropdowns using a static lookup table (client-side, not persisted until Save). Standard fields names are matched case-insensitively to metadata field slugs:

| API Field | Auto-matched metadata slug |
|-----------|---------------------------|
| brandValues | brainsuite_brand_values |
| brandValuesLanguage | brainsuite_brand_values_language |
| assetLanguage | brainsuite_asset_language |
| voiceOverLanguage | brainsuite_voice_over_language |
| assetName | brainsuite_asset_name (if exists) |

All other standard fields start as "— Unmapped —". Visual distinction between auto-matched and user-selected: none — auto-matched shows the same as user-picked. Admin must click "Save Mappings" to persist.
