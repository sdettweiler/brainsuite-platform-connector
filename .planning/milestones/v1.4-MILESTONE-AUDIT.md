## Critical Blockers

### BLOCKER-01: httpx.AsyncClient wrong kwarg in proxy test endpoint

**File:** `backend/app/api/v1/endpoints/super_admin.py`, line 370

**Current (broken):**
```python
async with httpx.AsyncClient(proxies={"https://": proxy_url}) as client:
```

**Fix:**
```python
async with httpx.AsyncClient(proxy=proxy_url) as client:
```

**Impact:** `POST /api/v1/super-admin/proxy-config/test` raises `TypeError: AsyncClient.__init__() got an unexpected keyword argument 'proxies'` on every call. httpx 0.25.2 uses `proxy=` (singular string), not `proxies=` (dict). The test suite patches httpx entirely so this TypeError is invisible to automated tests.

**Affected requirement:** PROXY-05

### BLOCKER-02: PROXY-02 live Google Ads download unvalidated

**Context:** The Google Ads proxy code path is identical to DV360 (which was validated successfully). However, the live UAT was blocked by two pre-existing issues:
1. Connected org includes MCC manager accounts — these reject metric queries with `REQUESTED_METRICS_FOR_MANAGER`
2. `youtube_cookies_runtime_expired` flag set from a prior rate-limit event blocks all downloads before the proxy path is reached

**Severity:** The code is correct, but production validation was never completed. PROXY-02 remains at code-verified status only.
